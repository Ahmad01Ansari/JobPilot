# JobPilot — Private Beta Backlog (Post-Beta Feature Queue)

> **Policy Directive:** JobPilot is currently in **Feature Freeze** for the Private Beta release (targeting 4–5 real users across Windows and Linux). All non-essential, large-scale feature proposals are recorded here and deferred until after beta acceptance.

---

## 1. Platform & OS Support Expansion
- [ ] **macOS Support:** Apple Silicon & Intel Universal packaged DMG, codesigning, and Apple Notarization pipeline.
- [ ] **Mobile Companion Webhook:** Push notification bridge to Discord, Telegram, or mobile notifications for real-time application updates and manual intervention requests.

## 2. Universal ATS & Portal Integrations
- [ ] **Enterprise ATS Support:** Expand Universal Agent archetypes to support SAP SuccessFactors, Oracle Cloud HCM, BambooHR, and SmartRecruiters.
- [ ] **Additional Job Portals:** Direct automation engines for ZipRecruiter, CareerBuilder, Dice, and StepStone.
- [ ] **Multi-Persona Profiles:** Support multiple active candidate profiles with hot-switching per job search cluster.

## 3. Advanced AI & Document Capabilities
- [ ] **Direct Native LLM Providers:** First-party API integration cards for Anthropic Claude direct API, Mistral AI, Cohere, and DeepSeek.
- [ ] **Automated Dynamic Resume Tailoring:** Automatic generation and compilation of targeted 1-page PDF resumes per job description based on verified candidate skills.
- [ ] **Automated Cover Letter Variations:** Dynamic cover letter generator with customizable tone sliders (executive, startup, technical specialist).

## 4. Communication & Interview Scheduling
- [ ] **Calendar OAuth Integration:** 2-way sync with Google Calendar and Microsoft Outlook for recruiter interview invitations and automatic meeting card generation.
- [ ] **Automated Thank-You Note Drafting:** Context-aware thank-you email drafting after completed interviews.

## 5. Analytics & Intelligence
- [ ] **Predictive Funnel Analytics:** Cohort response rate modeling (e.g. response likelihood by posting day, company size, and title level).
- [ ] **Salary Negotiation Copilot:** Real-time market benchmark comparator during job offer evaluation.
